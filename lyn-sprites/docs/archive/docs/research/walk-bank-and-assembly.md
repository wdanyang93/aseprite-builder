## 2. 자세·위상
측면: spread, xf, xb, lift_f/b, hand_f/b, arm_spread, lean. N/F(가까운 다리 앞/뒤) = 앞다리−뒷다리 밝기, 봉우리 run 단위 + 교대 강제. theta = 보폭 크기 + 닫힘/열림(발 들림 ≥1.5%H 또는 보폭 미분). phi = theta/2 (N) / .5+theta/2 (F).
정면: fw = 오른발 폭 − 왼발 폭(앞발이 넓다), dy, hand_r/l. 서 있는 구간(|fw|<8px) 은 idle. phi = (fw, −dfw/dt) 평면 각도. 착의 정면은 반전본(phi+0.5, 부호 반전, 손 교환, 꼬리 쪽 반전)으로 두 배.

## 3·4. 짝
측면 8짝 평균 거리 0.32, 다리 3~11px(4/8 만 36px), 팔 3~9px. 자세 거리 = 표준화 |Δspread|,|Δlift_f|,|Δlift_b|,|Δhand_f|,|Δhand_b|,|Δarm_spread| 평균 + 2·|Δtheta|, N/F 다르면 제외. 위상 창 ±0.07, 프레임 중복 금지.
정면: 나체 짝은 기록용. 기증 선택은 착의 자체 진폭 A(95%)로 목표 fw_i = A·cos(2πi/8), 위상 창 ±0.10 → +41, +26, +1, −22, −41, −26, −1, +30.
발견: 착의 정면 원화는 앞발 쪽으로 꼬리가 바뀐다(오른발 앞 = 꼬리 오른쪽), 나체 캐논은 항상 오른쪽 → 꼬리는 고정 레이어. 정면 원화의 fw 는 사각파(6장 벌림 → 1~2장에 교대).
