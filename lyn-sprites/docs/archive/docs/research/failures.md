# 시도했고 실패한 것 (다시 하지 말 것 / 하려면 왜 실패했는지부터 읽을 것)

날짜순. 각 항목: 무엇을 → 어떻게 측정 → 왜 실패 → 대신 무엇.

1. **색칠 데모 (dressdemo.py)** — 나체 위에 옷 색을 칠해 "입힌 것처럼" 보이게 함.
   사용자 판정: "색칠놀이가 아니다, 원화에서 크롭해서 입히는 것". → 옷 화소는 원화에서만.

2. **행 단위 워프 (gwarp.py, gwarp2.py)** — 몸축 t 별로 옷 행(run)을 몸 실루엣에 맞춰 늘림.
   IoU 0.825 였지만 **화소 재사용 24.2% (최대 21배)**, 무늬 번짐·옷 중복. 사용자: "왜 옷을 해체하나, 통째로".
   → 통째 이동 (gpiece.py, 재사용 0%). 찢어지지 않은 깨끗한 옷으로도 행 워프는 11~13% 찢김 → 방법의 문제.

3. **DensePose 식 다리별 차트 (legchart.py)** — 다리마다 별도 UV. IoU 0.865→0.778 로 악화.
   실루엣 길이로는 단축(foreshortening)과 실제 길이를 구분 못 함 — DensePose 가 학습 모델을 쓰는 이유.

4. **UIST 식 강체 파츠 자동 검출** — 5개 임계값에서 후보 0~3개. 강체 파츠는 검출이 아니라 **별도 레이어로 그려야** 한다.

5. **머리 좌우 판정을 홍채 색으로** — 갈색 가죽이 홍채 HSV 와 겹쳐 34/35장 뒤집힘. → 가지 분리(발은 두 갈래, 머리는 아님) 기하 규칙 + 시트 다수결.

6. **발만 보고 앞다리·좌우 판정** — 사용자: 얼굴 방향 → 진행 방향 → 발가락 순으로 큰 근거부터. 정면 원화는 발끝 y 차가 1px 라 '더 내려온다' 규칙이 거의 안 걸리고 **발 폭**(31/36) 으로 결정됨.

7. **위상 칸 평균끼리 옷 비교 (garmentstudy.py/frontstudy.py)** — 손발이 안 맞는 프레임끼리 평균. 사용자: 36장에서 시작점을 자세로 맞추고 8장을 골라 짝지어라. → sync.py/pairs8.py.

8. **실루엣 거리행렬 MDS 로 위상** — 두 보폭 봉우리가 지배해 원이 두 덩어리로 붕괴, 나체 반주기끼리 겹침. → 물리 정의 위상(보폭 크기 + 닫힘/열림 + N/F 밝기).

9. **발 들림 0.4%H(2~3px) 로 닫힘/열림 판정** — AI 가 발을 미끄러뜨려 그려서 뒤집힘. → 1.5%H 이상일 때만, 아니면 보폭 미분.

10. **옷 두께를 기준점(머리 x / 발 중점) 상대 좌표로 회귀** — 두 AI 캐릭터의 lean·비율·보폭이 달라 어떤 기준점을 잡아도 그 차이가 섞임 (다리 gap 음수 등). → 기준점 없는 폭 차이; 그래도 허벅지·무릎은 꼬리·망토 겹침으로 측정 불가.

11. **팔 마스크 = (피부∪장갑색) 성분** — 장갑·조끼·파우치·레깅스가 같은 갈색, 셔츠 무늬가 살색 → 몸통 절반이 팔로 잡힘 (25~32k px). → 절단선을 팔꿈치 위(t=0.42)로.

12. **허리 이음을 dx/dy 정렬로 제거** — 오차 64→63, 74→60. 원인은 정렬이 아니라 AI 무늬·팔 자체 차이. 이음 인지 기증 선택(A2)도 미미.

13. **상하체 분리 조합 (t=0.62, 팔 기증 + 다리 기증)** — 허벅지에서 두 프레임의 다리 자세가 달라 레깅스·망토 자락이 끊김. 같은 프레임이면 깨끗하지만 그러면 분리의 의미가 없음.

14. **페더 교차 합성에서 알파 합산** — (1−w) 아래 + w 위 를 순차 over 하면 절단 띠가 반투명. → 한쪽만 있는 화소는 그쪽 알파 유지, 둘 다 있으면 가중 평균 (assemble.blend).

15. **정면 기증을 나체 짝 기준으로 선택** — 나체 앞발 진폭 ±20px vs 착의 ±38px(장화) → 중립 프레임이 뽑힘. → 착의 자체 진폭으로 목표 fw_i = A·cos(2πi/8).

16. **정면 꼬리 쪽 필터** — 착의 원화는 앞발 쪽으로 꼬리가 바뀌어 한쪽만 남기면 반주기가 사라짐. → 기증 꼬리 삭제 + 고정 꼬리 레이어.
