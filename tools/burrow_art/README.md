# burrow_art — 원화 검수 · 결정론적 후처리

THE_BURROW 원화 파이프라인의 **코드 쪽 절반**입니다.

Slack `#굴-전체`에서 신호가 오가고 ChatGPT가 Drive에 컷신 원화를 생성하면,
각 요청의 `REQUEST.json` 안 `verify` 블록이 합격 기준이 됩니다.
이 도구는 그 기준을 **독립적으로 다시 측정**하고, 생성기가 스스로 기준을
맞추지 못할 때 이미지를 **규격에 맞게 고쳐 씁니다**.

## 왜 필요한가

`REQ_0002_M01`과 `REQ_0003_M02` 계열은 3회 생성에서 **시각 캐논은 매번 PASS**했지만
**기술 규격은 매번 똑같이 FAIL**했습니다.

| 항목 | 기준 | 3회 모두 잰 값 |
|---|---:|---:|
| 캔버스 | 1800 × 1500 | 1374 × 1145 |
| 부분 알파 | ≤ 0.5% | 66~69% |
| 투명부 비영 RGB | 0px | 611~872px |
| 순수 빨강 | 0px | 1,200~2,466px |
| 피사체 높이 | ≥ 1400px | 1374px |
| 경계 접촉 | 없음 | 사방 접촉 |

같은 값이 세 번 반복된다는 것은 생성기가 구조적으로 그 출력을 만든다는 뜻이고,
네 번째·다섯 번째 재생성으로는 달라지지 않습니다. 두 REVIEW.md가 모두 권고한
결정론적 후처리가 정확히 이 도구입니다.

## 사용법

```bash
pip install -r tools/requirements.txt
cd tools

# 검수만 — 규격 위반이 있으면 exit 1
python3 -m burrow_art -r /path/to/REQUEST.json verify frame_01.png frame_02.png

# 후처리 후 자동 재검수
python3 -m burrow_art -r /path/to/REQUEST.json normalize frame_*.png -o ./normalized
```

`-r`을 생략하면 현행 기본 규격(1800×1500, 부분 알파 ≤0.5%, 순수 빨강 0px,
피사체 높이 ≥1400px, 경계 비접촉)을 사용합니다.

## 후처리 순서

순서 자체가 규격입니다. 특히 **리샘플이 알파 이진화보다 먼저** 와야 합니다 —
반대로 하면 LANCZOS가 부분 알파를 그대로 되살립니다.

1. 알파 기준으로 피사체 bbox를 잘라낸다 (옅은 프린지는 `crop_threshold`로 무시)
2. 사방 `margin`을 남기는 최대 배율로 확대·축소한다 (LANCZOS)
3. 투명 캔버스 중앙에 배치한다 → 경계 접촉이 구조적으로 불가능해진다
4. 알파를 이진화한다 (`alpha_threshold`, 기본 128) → 부분 알파 해소
5. 티끌 덩어리를 제거한다 (8-연결, `speck_max_area` 이하)
6. 순수 빨강 화소를 주변 비(非)빨강 불투명 색으로 복구한다
   (고정된 8방향 순서 → 재현 가능). 끝내 주변 색을 찾지 못하면 투명 처리한다.
7. 투명한 곳의 RGB를 0으로 만든다

같은 입력은 항상 같은 바이트를 냅니다 (`test_normalize_is_deterministic`).

## 한계

- **시각 검수는 대체하지 않습니다.** 구도·표정·둥근 족제비 귀·복장 캐논 같은
  판단은 사람 몫이고, 이 도구는 측정 가능한 규격만 다룹니다.
- 후처리는 확대를 동반할 수 있습니다 (1145px → 1468px ≈ 1.28배).
  선이 물러 보이면 후처리가 아니라 생성 경로를 바꾸는 편이 낫습니다.
- `REQUEST.json`과 참조 원본은 절대 수정하지 않습니다 (WORKFLOW v3 §4).
