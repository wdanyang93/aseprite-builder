# sprite_harmonize — 스프라이트를 장면 조명에 맞추기 (scene-relight)

중립 조명으로 그린 2D 캐릭터 프레임을 배경 장면의 빛으로 다시 칠한다.
장면마다 **손으로 칠한 참고 그림 한 장**에서 빛을 한 번 배우고, 그 뒤로는 **참고 없이 모든 프레임·모든 방향**에 적용한다.

- Claude Cowork 에서는 이 폴더가 그대로 스킬이다 → [`SKILL.md`](SKILL.md)
- 명령: [`relight.py`](relight.py) (`fit` / `apply` / `preview` / `check`)
- 코드: [`scenelight/`](scenelight) · 테스트: [`tests/`](tests) · 장면 프로필: [`scenes/`](scenes) · 연구 기록/실패: [`RESEARCH.md`](RESEARCH.md)

```bash
pip install -r requirements.txt
python relight.py fit neutral.png reference.png -o scenes/forest_sunset.json --sheet check.png   # 장면마다 한 번 (~1.5분)
python relight.py apply scenes/forest_sunset.json frames/*.png -o out/ --view-from-name --sheet ba.png   # 프레임당 1~3초
python relight.py preview scenes/forest_sunset.json frames/walk_03.png --bg bg.png --place 640,602,240 -o shot.png
```

## 방법

| 단계 | 내용 | 왜 |
|---|---|---|
| 정렬 | 중립 → 참고: 실루엣 IoU 최대 닮은꼴 변환 + 광류(DIS) | 두 그림을 화소 단위로 비교하려고. 부위 이름표가 필요 없다 |
| 색 | 재질별(피부 / 흰 천·털·머리 / 어두운 천) Lab 평균·분산 맞춤, 어두운 천은 채널 곱 | 한 가지 주황을 곱하면 태닝처럼 까매졌다. 갈색이 보라로 바뀌지 않게 |
| 면 방향 | **몸 전체** 실루엣의 Poisson 부풀림 (가슴 타원체는 기본으로 끔) | 부위마다 부풀리면 허벅지가 파이고 옷 사이에 검은 줄이 생겼다. 타원체는 가슴 모양을 바꿨다 |
| 명암 | 주광(감싸는 Lambert) + 역광 + 법선 선형항, 부드러운 L* 오프셋으로 **더함**. 원화 자체 명암은 절대 빼지 않는다 | 선·무늬·가슴 모양은 그대로, 빛만 바뀐다 |
| 털 역광 | 얇은 털·머리 가장자리에 주황 투과광 | 참고의 꼬리 끝 빛 |
| 배우기 | 참고와의 차이를 격자 영역별로 최소제곱 (정렬이 나쁜 영역은 가중치 ↓, 윗몸 띠 ×3) → 숫자 20여 개 | 프로필은 ~2 KB JSON. 화소 지도를 저장하지 않으니 다른 프레임에도 쓸 수 있다 |
| 합성 | 발밑 그림자, 가장자리 빛 번짐, 장면 안 밝기 | 떠 보이거나 오려 붙인 느낌 제거 |

방향 힌트는 파일 이름에서 읽을 수 있다 (`--view-from-name`: `s/se/e/n...`, `남동` 등). 가슴 타원체를 켤 때만 쓰인다 (뒤: 없음, 옆: 하나).

## 검증 (숲 석양, 린 · 중립 1024×1536 ↔ 따뜻한 참고)

평가 도구는 참고 그림에 부위를 표시해 두고 부위×재질마다 "명암 모양 일치도"(저주파 L* 상관, 1 = 완전 일치)를 잰다.
"원화 모양 보존"은 원래 그림의 가슴 가운데 명암(그림 높이 6% 이하 크기)이 얼마나 그대로인지다 (1 = 그대로).

| 방법 | 부위 평균 | 가슴 피부 | 윗옷 천 | 색 오차 | 원화 모양 보존 | 평균 L* (참고 66.0) |
|---|---|---|---|---|---|---|
| 중립 (지금 게임 그림) | 0.599 | 0.74 | 0.86 | 24.3 | 1.000 | 79.9 |
| v1 (주황 하나 곱 + 림) | 0.467 | 0.53 | 0.84 | 7.3 | 0.995 | 66.8 |
| v4 색 식 (색만) | 0.595 | 0.74 | 0.86 | 5.6 | 1.000 | 65.5 |
| 가슴 타원체 버전 (첫 배포) | 0.832 | 0.93 | 0.88 | 5.5 | 0.906 ✗ | 66.0 |
| **이 도구 (지금 기본값)** | **0.812** | **0.90** | **0.87** | **5.9** | **0.990** | **66.0** |

- 첫 배포는 가슴 타원체가 실제 가슴과 어긋나 **가운데 가슴 모양이 바뀌어 보였다**. 지금은 타원체를 끄고 원화 명암을 빼지 못하게 해서
  모양은 그대로 두고 빛만 바꾼다. 참고 일치는 조금만 내려갔다. 자세한 비교와 실패 목록: [`RESEARCH.md`](RESEARCH.md).
- 이름표 없는 fit 이 이름표를 쓴 연구판과 거의 같다 → 새 장면에서도 참고 한 장이면 된다.
- 턴어라운드 8방향 그림(다른 옷, 참고 없음)에 적용해도 빛 방향이 일관되고 깨지지 않는다.
- 합성 인형으로 불변식 테스트 14개 (알파 보존, 결정성, 빛 방향 학습, **원화 모양 보존** 등): `python -m pytest -q tests`.
- `fit`/`check` 가 `drawn form kept` 를 출력한다. 0.95 미만이면 경고한다.

## 한계
- 새 장면은 그 장면의 참고 그림 한 장이 있어야 한다 (포즈·구도가 같은 것. 정렬 IoU < 0.85 면 경고).
- 가슴을 따라 휘는 빛은 원화에 그려진 명암 + 몸 윤곽 빛에서 나온다. 참고처럼 가슴 모양 자체를 다시 조각하지는 않는다 (모양이 바뀌기 때문).
- 참고의 꼬리 끝처럼 아주 강한 투과광은 조금 약하게 나온다.
- 픽셀아트용이 아니다.
- 턴어라운드처럼 원래 피부가 아주 창백한 그림은 결과 피부가 참고 피부 색(L* ~70)으로 가서 원본보다 많이 짙어 보일 수 있다.
