# sprite_harmonize — 스프라이트를 장면 조명에 맞추기 (scene-relight)

중립 조명으로 그린 2D 캐릭터 프레임을 배경 장면의 빛으로 다시 칠한다.
장면마다 **손으로 칠한 참고 그림 한 장**에서 빛을 한 번 배우고, 그 뒤로는 **참고 없이 모든 프레임·모든 방향**에 적용한다.

- Claude Cowork 에서는 이 폴더가 그대로 스킬이다 → [`SKILL.md`](SKILL.md)
- 명령: [`relight.py`](relight.py) (`fit` / `apply` / `preview` / `check`)
- 코드: [`scenelight/`](scenelight) · 테스트: [`tests/`](tests) · 장면 프로필: [`scenes/`](scenes) · 연구 기록/실패: [`RESEARCH.md`](RESEARCH.md)

```bash
pip install -r requirements.txt
python relight.py fit neutral.png reference.png -o scenes/forest_sunset.json --pack scenes/forest_sunset.pack --sheet check.png  # 장면마다 한 번
python relight.py apply scenes/forest_sunset.json frames/*.png -o out/ --pack scenes/forest_sunset.pack --view-from-name --sheet ba.png
python relight.py preview scenes/forest_sunset.json frames/walk_03.png --bg bg.png --place 640,602,240 -o shot.png
```

## 두 가지 모드
- **참고 팩 (`--pack`)** — 참고 그림의 실제 빛·색을 옮긴다. 참고와 같은 방향의 프레임에 쓴다 (참고 일치 0.898, 원화 모양 보존 0.953).
  참고를 중립 그림 모양에 화소 단위로 맞춰 두고, 프레임마다 **그 프레임 자신의 색과 비교해** 차이를 옮긴다 (중립의 세부가 찍히지 않음).
  몸 안쪽은 부드러운 빛·색만(그림 높이 1.5%), 실루엣 가장자리는 참고의 림을 윤곽을 따라, 선은 밝아지지 않게. 선·무늬는 그대로.
  관문 (크기와 무관하게, 그림 높이를 중립에 맞춘 뒤 잼): 접힘 ≤ 0.055, 구조 일치 ≥ 0.68, 흐름 전 실루엣 겹침 ≥ 0.71
  (40여 사례로 맞춤: 같은 그림·다시 그린 그림·옷 바뀜은 통과, 다른 방향·옷·좌우반전·잘린 그림은 통째로 워시+림).
  `apply` 는 방향 묶음 단위로 판단해서 한 애니메이션 안에서 깜빡이지 않는다 (묶음은 강등만 함).
  **가슴 단계** (`scenelight/chest.py`, 기본 켜짐): 가슴 구역에서만 참고의 빛을 가는 크기(그림 높이 0.4%)로, **그려진 선을 벽으로 쓰는**
  필터를 거쳐 옮긴다 → 하이라이트가 골 선·컵 윤곽에서 끊기는 참고의 입체감. 컵 무늬 대비 40%, 선은 밝아지지 않음.
  가슴 벤치: 중립 0.81 → 0.90, 흉내 프레임 0.81~0.84 → 0.92~0.93 (RESEARCH.md 12번).
  팩에는 그림 데이터가 들어 있어 공개 저장소에 올리지 않는다 (`.gitignore`).
- **워시 + 림** — 팩이 없거나 프레임이 안 맞을 때. 아래 표의 방법.

## 방법 (워시 + 림)

| 단계 | 내용 | 왜 |
|---|---|---|
| 정렬 | 중립 → 참고: 실루엣 IoU 최대 닮은꼴 변환 + 광류(DIS) | 두 그림을 화소 단위로 비교하려고. 부위 이름표가 필요 없다 |
| 색 | 재질별(피부 / 흰 천·털·머리 / 어두운 천) Lab 평균·분산 맞춤, 어두운 천은 채널 곱 | 한 가지 주황을 곱하면 태닝처럼 까매졌다. 갈색이 보라로 바뀌지 않게 |
| 빛 | **워시**(그림 전체에 걸친 완만한 밝기 기울기) + **림**(실루엣 가장자리의 얇은 띠, 목·겨드랑이 같은 오목한 곳은 자동으로 약하게) | 몸 안쪽에는 어떤 모양도 새로 만들지 않는다 |
| 몸 안 명암 | 원화에 그려진 명암을 그대로 둔다 (절대 빼지 않는다) | 가슴·골·배 모양이 원래 그림 그대로 |
| 털 역광 | 얇은 털·머리 가장자리에 주황 투과광 | 참고의 꼬리 끝 빛 |
| 배우기 | 참고와의 차이를 격자 영역별로 최소제곱 (정렬이 나쁜 영역은 가중치 ↓, 윗몸 띠 ×3) → 숫자 10여 개 | 프로필은 ~2 KB JSON. 화소 지도를 저장하지 않으니 다른 프레임에도 쓸 수 있다 |
| 합성 | 발밑 그림자, 가장자리 빛 번짐, 장면 안 밝기 | 떠 보이거나 오려 붙인 느낌 제거 |

방향 힌트는 파일 이름에서 읽을 수 있다 (`--view-from-name`: `s/se/e/n...`, `남동` 등). 지금 기본 빛(워시+림)은 방향과 상관없이 같은 화면 방향 빛을 준다.

## 검증 (숲 석양, 린 · 중립 1024×1536 ↔ 따뜻한 참고)

평가 도구는 참고 그림에 부위를 표시해 두고 부위×재질마다 "명암 모양 일치도"(저주파 L* 상관, 1 = 완전 일치)를 잰다.
"원화 모양 보존"은 원래 그림의 가슴 가운데 명암(그림 높이 6% 이하 크기)이 얼마나 그대로인지다 (1 = 그대로).

| 방법 | 부위 평균 | 가슴 피부 | 윗옷 천 | 색 오차 | 원화 모양 보존 | 평균 L* (참고 66.0) |
|---|---|---|---|---|---|---|
| 중립 (지금 게임 그림) | 0.599 | 0.74 | 0.86 | 24.3 | 1.000 | 79.9 |
| v1 (주황 하나 곱 + 림) | 0.467 | 0.53 | 0.84 | 7.3 | 0.995 | 66.8 |
| v4 색 식 (색만) | 0.595 | 0.74 | 0.86 | 5.6 | 1.000 | 65.5 |
| 가슴 타원체 버전 (첫 배포) | 0.832 | 0.93 | 0.88 | 5.5 | 0.906 ✗ 가슴 가운데 모양 바뀜 | 66.0 |
| 타원체 끔, 실루엣 Lambert (둘째) | 0.812 | 0.90 | 0.87 | 5.9 | 0.990 (윗가슴에 대각선 빛 경계 ✗ 불룩해 보임) | 66.0 |
| 워시 + 림 (팩 없을 때) | 0.757 | 0.84 | 0.86 | 6.4 | 0.995 | 66.0 |
| 참고 팩 (`--pack`, 가슴 단계 전) | 0.898¹ | — | — | 2.4¹ | 0.953 | 66.3 |
| **참고 팩 + 가슴 단계 (지금 기본)** | **0.900**¹ | — | — | **2.2**¹ | 0.953² | **66.1** |

¹ 이 열은 이름표 없는 격자 지표(`fit` 출력) 기준이다: 같은 지표로 워시+림 0.668 / 색 오차 6.8, 중립 0.476.
² 몸 전체 부드러운 전달의 값. 가슴 단계가 들어간 최종 결과는 0.897 — 가슴 안쪽이 일부러 참고의 빛을 따르기 때문이다(사용자 요구).
흉내 낸 애니메이션 프레임(팔·다리·크기·기울기 변형)에서 참고 빛이 몸을 따라간다. 다른 옷 턴어라운드 8방향(1×·1.8×·3×)은 전부 워시+림.
팩 사용 시 프레임당 약 5초 (게이트만 0.3~0.7초), 작업 그림 높이 1024 px.

- 첫 배포는 가슴 타원체가 실제 가슴과 어긋나 **가운데 가슴 모양이 바뀌어 보였다**. 둘째 판은 실루엣 부풀림 위의 주광이
  목·어깨 오목한 곳에서 윗가슴으로 대각선 빛 경계를 만들어 **가운데 위쪽이 불룩해 보였다**. 지금은 몸 안쪽에는 완만한 기울기만,
  가장자리에는 얇은 림만 더하고, 원화 명암은 그대로 둔다. 참고 일치는 내려갔지만 그림 모양은 바뀌지 않는다. 자세한 비교와 실패 목록: [`RESEARCH.md`](RESEARCH.md).
- 이름표 없는 fit 이 이름표를 쓴 연구판과 거의 같다 → 새 장면에서도 참고 한 장이면 된다.
- 턴어라운드 8방향 그림(다른 옷, 참고 없음)에 적용해도 빛 방향이 일관되고 깨지지 않는다.
- 합성 인형으로 불변식 테스트 22개 (알파 보존, 결정성, 빛 방향 학습, **원화 모양 보존**, **몸 안쪽에 모양을 만들지 않음** 등): `python -m pytest -q tests`.
- `fit`/`check` 가 `drawn form kept` 를 출력한다. 0.95 미만이면 경고한다.

## 한계
- 새 장면은 그 장면의 참고 그림 한 장이 있어야 한다 (포즈·구도가 같은 것. 정렬 IoU < 0.85 면 경고).
- 워시+림 모드의 가슴 빛은 원화에 그려진 명암 + 가장자리 림에서 나온다. 참고처럼 가슴 안쪽 입체감을 내는 것은 팩 모드의 가슴 단계뿐이다
  (참고 그림과 같은 방향의 프레임만). 몸 안쪽 명암을 지어내는 방법은 네 번 해 봤고 모두 모양이 바뀌어 보이거나 어둡게만 했다.
- 참고의 꼬리 끝처럼 아주 강한 투과광은 조금 약하게 나온다.
- 픽셀아트용이 아니다.
- 턴어라운드처럼 원래 피부가 아주 창백한 그림은 결과 피부가 참고 피부 색(L* ~70)으로 가서 원본보다 많이 짙어 보일 수 있다.
