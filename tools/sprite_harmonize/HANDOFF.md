# 인수인계 — scene-relight (다른 Claude 에게 이 파일부터 읽게 한다)

## 한 줄 요약
중립 조명으로 그린 캐릭터 프레임을 장면 빛(지금은 숲 석양)에 맞게 다시 칠하는 도구.
장면마다 참고 그림 한 장으로 빛을 한 번 배우고(`fit`), 모든 프레임에 적용한다(`apply`).

## 지금 상태 — 두 가지 모드
**A. 참고 팩 (`--pack`, 사용자의 최신 요구 "참고처럼 명암"):** 팩 = 중립 + 중립 모양에 맞춘 참고 + 신뢰도 지도 (v2).
프레임마다: 그림 높이를 중립에 맞추고(작업 높이 1024 px) 중립을 프레임에 맞춘 뒤 관문(접힘 ≤ 0.055, 구조 일치 ≥ 0.68,
흐름 전 겹침 ≥ 0.71) → 통과하면 참고를 그 **프레임 자신의 색과 비교한** 차이만 더한다: 몸 안쪽은 1.5% 부드러운 빛·색,
실루엣 가장자리는 참고 림을 거리 띠별로(윤곽 따라), 선은 밝아지지 않음, 찢어진 흐름 구역은 신뢰도 0.
`apply` 는 방향 묶음별로 판단(강등만), 프레임마다 바로 저장. 린 숲 석양: 참고 일치 0.898 (B 0.670·같은 지표),
원화 모양 보존 0.953 (몸 전체 부드러운 전달), 색 오차 2.4. 다른 옷 턴어라운드 8방향(여러 크기)·좌우반전·잘린 그림은 전부 B.
팩에는 사용자 그림이 들어 있다 → 공개 저장소 금지 (`.gitignore`), zip 으로만 전달.

**A+. 가슴 단계 (`scenelight/chest.py`, 팩 모드에서 기본 켜짐, `--no-chest` 로 끔):** 사용자 요구 "가슴 안쪽이 빛에 따른 입체감을
못 낸다 / 영역 선택 + 밝기·색 보정이 내가 원하는 것", 다음 날 "방법은 맞는데 빛이 약하다, 참고만큼". 관문을 통과한 프레임마다 그 프레임
그림에서 컵 두 개를 찾고(선으로 막힌 워터셰드), 가슴 구역 안에서만 참고의 빛을 가는 크기(천 0.3%, 피부 0.2%)로 옮긴다. 저역 통과
필터가 **그려진 선을 벽으로** 쓰므로 하이라이트가 골 선·컵 윤곽에서 끊긴다. **진짜 선(어두운 획)만 선**이고 컵 무늬는 천으로 빛을 받는다
(무늬를 선으로 쳤던 첫 판은 컵이 2 L* 어두워 "약하다"는 말을 들었다). 선은 밝아지지 않고, 선 가장자리는 옆 면의 빛만, 구역 밖은 그대로.
강도 벤치(참고와의 영역별 밝기 차, 0 = 같음): 강도 오차 1.90 → 0.75, 평균 −1.34 → −0.05 L*, 하이라이트 −4.0 → −0.8 L*, 가슴 상관 0.945,
프레임 간 흔들림은 이전 판보다 작다. 컵을 못 찾으면 건너뛰고 `chest light: skipped (이유)`. 숫자·남은 차이: RESEARCH.md 12·13번.

**B. 워시 + 림 (팩 없거나 프레임이 안 맞을 때):**
- 빛 = **워시**(그림 전체의 완만한 밝기 기울기) + **림**(실루엣 가장자리의 얇은 빛, 목·겨드랑이 같은 오목한 곳은 약하게)
  + 털 가장자리 주황 역광. 색은 재질별(피부 / 흰 천·털·머리 / 어두운 천)로 맞춘다.
- **몸 안쪽에는 어떤 모양도 새로 만들지 않는다.** 원화의 명암(가슴·골·배)은 그대로 둔다.
- 숫자 (린, 참고 대비): 원화 모양 보존 0.995, 몸 안쪽 비평면 빛 0.04 L*, 참고 일치 0.757 (중립 0.599), 평균 L* 66.0 = 참고.

## 왜 이렇게 됐나 (사용자 지적 → 고침)
0. B 만으로는 "아직도 참고와 다르다" → 참고의 실제 명암을 옮기는 A 를 추가.
4. A 의 가슴 안쪽이 평평하다("빛에 따른 입체감 없음") → 가슴 단계(A+). 부풀림+조명 모델과 컵 좌표 템플릿은 적대적 검토에서
   탈락(어둡게만 함 / 둥근 빛 덩어리). Adobe 로도 해 봤다(아래).
5. 가슴 단계가 참고보다 약하다 → 원인(컵 무늬를 선으로 침)을 없애고 세 번 고침. 영역별 분위수 맞춤(B)은 끈 바램·흔들림으로 탈락.
1. 가슴 타원체를 얹었더니 **가운데 가슴 모양이 바뀌어 보였다** → 타원체 끔 (`geo.bh = 0`).
2. 맞춤이 원화 피부 명암을 −0.33배 **지웠다** → 원화 명암 계수 ≥ 0 (더하기만).
3. 실루엣 부풀림 위 주광이 목→오른쪽 가슴 **대각선 빛 경계**를 만들어 **윗가슴 가운데가 불룩해 보였다**
   → 빛 모델을 워시 + 얇은 림으로 교체 (`cfg.model = "wash"`).
자세한 수치와 다른 실패들: `RESEARCH.md`.

## Adobe (Claude Cowork 에서 쓸 때)
지금은 연결된다 (환경 허용 도메인에 Adobe 추가 후). 해 본 것: 업로드 → `image_select_subject`(bodyParts "Upper Clothes" 마스크 정확) →
`image_apply_adjustments` + `maskURI`(우리가 계산한 밝게/어둡게 마스크) → 가슴 벤치 0.81 → 0.956 (중립 한 장).
주의: (1) **Adobe 가 가장자리 알파를 바꾼다**(253 → 255, 1 → 4, 3만여 화소) → 결과의 RGB 만 쓰고 알파는 원본으로 되돌린다.
(2) 세기 비대칭: 밝기 +40 = 마스크 1 당 +8.6 L*, −40 = −19 L*. (3) 컵·가슴을 말로 고르는 `image_select_by_prompt` 는 "unsafe prompt" 로 거절된다.
(4) `image_apply_adjustments` 전에 입력마다 `asset_inline_preview` 필수. 같은 일을 코드(가슴 단계)가 정확하게 하므로 기본은 코드,
Adobe 는 손 보정용이다.

## 절대 하지 말 것
- 가슴 타원체(`geo.bh > 0`)나 옛 빛 모델(`cfg.model = "normals"`)을 다시 켜기.
- 원화 명암을 빼는 방향의 계수 허용.
- 참고와 더 닮게 하려고 몸 안쪽 명암을 **지어내기** (타원체·실루엣 법선·부풀림 조명·둥근 빛 덩어리로 네 번 해서 모두 탈락).
  참고를 닮게 하려면 A(참고의 실제 명암을 옮기기)와 가슴 단계(A+, 참고의 빛을 선 안에서만)를 쓴다.
- 가슴 단계에서 선 보호를 끄거나 구역(`CHEST["up"]`)을 목까지 넓히기 (윤곽이 얇아지고 목·턱 그림자가 바뀌었다).
- 가슴 단계에 전체 배수(gain)를 곱해서 "더 세게" 하기: 약했던 원인은 무늬 분류였고, 배수는 선·끈까지 밝힌다. 강도는 가슴 영역별 밝기(평균·밝은 끝)를
  참고와 비교해서 확인한다 (RESEARCH.md 13번의 표).
- 안 맞는 프레임에 참고 명암을 섞기, 관문 기준을 근거 없이 바꾸기 (40여 사례로 맞춘 값: `RESEARCH.md` 11번).
- 몸 안쪽 sigma(`SIGMA_IN`)를 1.5% 아래로 낮추기: 몸 전체 원화 모양 보존이 0.95 아래로 떨어진다 (가슴만 가는 크기로 하는 것은 가슴 단계가 한다).
- lyn-sprites 원화 파츠(`assets/parts/`)에 적용하기 — 렌더된 최종 프레임에만 쓴다.

## 확인 방법
```bash
pip install -r requirements.txt
python -m pytest -q tests          # 22개 통과해야 함
python relight.py apply scenes/forest_sunset.json 프레임/*.png -o 결과/ --pack scenes/forest_sunset.pack --view-from-name --sheet 전후.png
```
`fit`/`check` 출력의 `drawn form kept` 가 0.95 미만이면 모양이 바뀐 것 → 사용자에게 이미지와 함께 알린다.
팩이면 `soft transfer (body): drawn form kept` 를 본다. 가슴 단계가 켜진 결과 값(약 0.83)은 가슴 안쪽이 일부러 참고를 따르기 때문에 낮다.
`apply` 출력에서 프레임마다 `chest light: on` 인지 확인하고, 가슴 확대 이미지를 사용자에게 보여 준다.
