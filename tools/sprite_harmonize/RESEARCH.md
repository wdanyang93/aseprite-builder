# 연구 기록 — 무엇을 해 봤고 무엇이 실패했나

대상: 린 (중립 1024×1536, 3/4 걷기) ↔ 사용자가 만든 따뜻한 참고 (숲 석양). 평가 도구는 참고 그림에 부위를 표시하고
부위×재질마다 **참고와의 명암 모양 일치도**(저주파 L* 상관)를 잰다. 여기에 **원화 모양 보존**을 함께 잰다:
원래 그림의 가슴 가운데(윗몸 띠, 실루엣 가장자리에서 떨어진 곳)에서 작은 크기(그림 높이의 6% 이하) 명암이 그대로 남았는지. 1 = 그대로다.

## 결과

| 방법 | 참고 일치 (부위 평균) | 가슴 피부 / 윗옷 천 | 색 오차 | 원화 모양 보존 | 판정 |
|---|---|---|---|---|---|
| 중립 (지금 게임 그림) | 0.599 | 0.74 / 0.86 | 24.3 | 1.000 | 색이 장면과 다름 |
| v1: 주황 하나 곱 + 림 | 0.467 | 0.53 / 0.84 | 7.3 | 0.995 | 태닝처럼 까매짐 |
| v4 색 식 (재질별 색만) | 0.595 | 0.74 / 0.86 | 5.6 | 1.000 | 가슴 명암이 원래 그림 그대로 |
| 가슴 타원체 (primitives) | **0.840** | **0.95 / 0.92** | 5.7 | 0.898 | **가슴 모양이 바뀜** (아래 1번) |
| 회귀 (regress, 94개 특징) | 0.833 | 0.91 / 0.93 | 5.1 | 0.945 | 교차검증 0.76 → 과적합 |
| 원화 명암에서 모양 (sfs) | 0.826 | 0.91 / 0.84 | 4.9 | 0.978 | 윗옷 천 개선 없음 |
| 선에서 법선 (lumo) | 0.781 | 0.92 / 0.85 | 5.2 | — | 참고 일치 낮음 |
| 몸 윤곽 Lambert + 원화 명암 보존 | 0.812 | 0.90 / 0.87 | 5.9 | 0.990 | **윗가슴 가운데가 불룩해 보임** (아래 9번) |
| **채택: 워시 + 림 + 원화 명암 보존** | 0.757 | 0.84 / 0.86 | 6.4 | **0.995** | 몸 안쪽에 모양을 만들지 않음 |

참고와 더 닮게 맞추려 할수록 원화의 가슴 모양을 바꾸는 경향이 있었다 (참고 그림은 다시 그린 그림이라 가슴 모양 자체가 다르다).
그래서 **모양 보존을 먼저 지키고 그 안에서 참고에 맞춘다**를 기준으로 골랐다.

## 실패한 것 (사실대로)
1. **가슴 타원체** — 윗옷 흰 천 덩어리로 가슴 위치를 추정해 타원체를 얹었다. 참고 일치는 가장 높았지만,
   타원체가 실제 가슴보다 위에 앉아 **왼쪽 가슴 위 윗가슴에 밝은 점, 왼쪽 가슴 아래 안쪽에 어두운 얼룩**이 생겨
   가운데 가슴 모양이 바뀌어 보였다 (사용자 지적). 두 타원체를 max 로 합쳐 생긴 V자 접힘도 한몫. 부드러운 합치기(smooth max)로 0.866 → 0.935 까지만 좋아졌다. → 기본값에서 뺐다.
2. **원화 명암 지우기** — 맞춤이 원화 자체의 피부 명암을 −0.33 배 빼는 쪽으로 갔다 (참고 가슴 명암이 다르니까).
   골·가슴 아래 그늘이 약해져 모양이 달라 보였다. → 계수를 0 이상으로 묶었다 (더하기만 가능, 빼기 금지).
3. **한 가지 주황 곱** (v1) — 태닝, 피부 L* 64. 한 가지 빛을 곱하면 흰 천·털도 같이 어두워진다.
4. **부위마다 부풀리기** (v4 이전) — 허벅지가 치마 끝에서 파이고 윗옷·아랫옷 사이에 검은 줄. → 몸 전체 윤곽 하나로만 부풀린다.
5. **L 히스토그램 맞추기** (v1 참고 모드) — 서로 다른 그림 사이의 곡선이 가팔라져 피부가 얼룩덜룩. → 평균·분산 맞추기로 바꿨다.
6. **최소제곱 색 맞추기** — 정렬이 완벽하지 않아 명암 대비가 0.45~0.74 배로 줄었다. → 재질별 평균·분산 맞추기.
7. **회귀 모델** — 한 쌍으로 94개 특징을 배우면 학습 0.833 / 교차검증 0.76. 다른 프레임에서 믿기 어렵다.
8. **Adobe 부위 마스크** — 이 작업 환경에서 `at.adobe.com` 업로드가 네트워크 정책에 막혔다. 부위 이름표 없이 격자 영역 + 재질(색)으로 맞추도록 바꿨고,
   이름표를 쓴 연구판과 거의 같은 결과(0.832 vs 0.841)가 나왔다.
9. **실루엣 부풀림 위 주광 (Lambert)** — 타원체를 끈 뒤에도 사용자가 "가슴 가운데 위쪽이 불룩하다"고 지적.
   원인 둘: (a) 맞춘 주광이 감싸기 0.03 (단단한 명암 경계)에 약간 뒤쪽이라, 몸통+팔이 붙은 실루엣이 꺾이는 선을 따라
   목에서 오른쪽 가슴까지 대각선 빛 경계가 생겼다. (b) 거리 기반 림 띠가 목·머리·어깨 사이 오목한 곳에서 윗가슴으로 70~100 px 번졌다.
   부드러운 경계·감싸기 하한으로는 모서리만 흐려질 뿐 띠가 남았다 (빛 모서리 지표 24.8 → 12.1).
   → 빛 모델을 워시(완만한 기울기) + 얇은 림(오목한 곳 자동 약화)으로 바꿨다. 빛 모서리 10.5, 몸통 안쪽 비평면 성분 0.9 → 0.04 L*.
   참고 일치는 0.812 → 0.757 로 내려갔다 — 모양을 지키는 값이다.

10. **사용자: "아직도 참고와 다르다. Adobe 같은 걸로 참고처럼 안 돼?"** — Adobe 커넥터는 이 환경에서 업로드(`at.adobe.com`)가 막혀 있고,
   되더라도 마스크·보정만 있어 다시 칠하기(Harmonize)는 없다. 대신 **참고 팩**: 참고를 중립 모양에 맞춰 참고 자체의 명암을 옮긴다.
   - 한 층(0.8%)만: 참고 일치 0.826, 적용 범위 62% (꼬리·머리·치마처럼 다시 그려진 곳은 꺼짐).
   - + 거친 층(3%): 0.880 / 91% — 꼬리 끝 주황빛, 밝은 머리까지 옮겨짐.
   - 신뢰도 지도를 그림 안에서만 흐리게(바깥 빈 배경을 섞지 않게) + 둘 다 평평한 곳은 "일치"로: 0.915 / 98%.
   - 실패: 처음 게이트(IoU ≥ 0.8)는 다른 옷 정면 그림에 참고 명암을 23% 섞어 얼룩졌다 → IoU ≥ 0.9 + 구조 일치 ≥ 0.6 (다른 옷 0.49 vs 같은 그림 0.98), 안 맞으면 통째로 워시+림.
   - 한계: 실제 AI 동작 프레임으로는 아직 검증 못 함 (여기 있는 건 중립을 변형한 흉내 프레임). 실제 프레임은 그림이 조금씩 달라 구조 일치가 0.6 아래로 떨어질 수 있다 → 출력의 match 값을 보고 `--min-match` 조정.

11. **적대적 검토 3명 (시각·관문·코드) → 고침 (팩 v2)**
   - 다른 옷 뒷모습을 크게 키우면 관문 통과(해상도에 따라 점수가 변함) → 프레임을 중립 그림 높이로 맞춘 뒤 판단, 흐름 뒤 IoU 대신
     접힘 비율(야코비안 ≤ 0) + 흐름 전 겹침 + 구조 일치. 40여 사례 보정: 통과군 match ≥ 0.84·fold ≤ 0.037·IoU ≥ 0.75,
     대체군 match ≤ 0.52·fold ≥ 0.084·IoU ≤ 0.67 → 관문 0.68 / 0.055 / 0.71.
   - 팩이 가슴 가운데 모양을 바꿈(원화 모양 보존 0.918) + 밝은 쪽 림이 오히려 어두워짐 → 몸 안쪽 sigma 와 가장자리 띠별 림을 분리.
     안쪽 sigma 를 0.015~0.06 으로 훑어서 모양 보존 ≥ 0.95 인 가장 작은 값 1.5% 선택 (참고 일치 0.898 / 보존 0.953).
   - 중립의 세부가 다른 프레임에 찍힘(옷 바뀐 프레임에 매듭 자국) → 팩에 차이 대신 "중립 모양에 맞춘 참고"를 저장하고 프레임마다 자기 색과 비교.
   - 선이 6.7 L* 밝아짐 → 선 화소는 밝아지지 못하게.
   - 팔을 크게 움직이면 흐름이 찢어져 네모 얼룩 → 유효 구역(두 알파 모두 + 열림 연산)만 쓰고 그림 안에서 매끄럽게: 얼룩 없어짐.
   - 같은 묶음 안에서 프레임마다 참고/워시가 바뀌어 깜빡임 → 방향 묶음별 판단(강등만).
   - 작은 그림이 큰 캔버스에 있으면 작업 캔버스가 4176² 로 커져 201초·4.5GB → 그림만 잘라서 처리, 작업 높이 1024 px.
     닮은꼴 탐색이 비연속 배열 때문에 12배 느렸음 → 연속 배열. 결과: 프레임당 31초 → 5초.
   - 빈 프레임에서 전체 배치가 죽고 아무것도 저장 안 됨 → 빈 프레임 보호, 프레임마다 예외 처리·즉시 저장.

## 아직 안 된 것
- 윗옷 천의 참고 일치는 0.87 (중립 0.86) — 거의 그대로다. 참고의 천 명암은 다시 그린 천 주름이라 옮기면 모양이 바뀐다.
- 참고의 꼬리 끝 같은 강한 투과광은 약하게 나온다.
- 가슴 모양을 바꾸지 않으면서 가슴을 따라 휘는 빛을 더 넣으려면, 원화 선(가슴 윤곽선)에 정확히 맞는 모양이 필요하다.
  Adobe 부위 마스크(가슴·팔·다리)를 쓸 수 있게 되면 그 윤곽으로 다시 시도할 수 있다.
